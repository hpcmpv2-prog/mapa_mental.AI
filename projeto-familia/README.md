# Família — Uma sociedade, diferentes famílias

Website educativo com um mapa mental interativo sobre a família, desenvolvido para um trabalho de Área de Integração e com componente prática de GPSI.

## Funcionalidades
- Página inicial ilustrada com botão **Iniciar**.
- Mapa mental com oito ramos principais e subdivisões, apresentados abertos por defeito.
- Seleção de conceitos com definições no painel lateral esquerdo.
- Controlos para expandir ou recolher os ramos.
- Layout adaptável a computadores, tablets e telemóveis.

## Como executar
Não necessita de instalação nem de dependências.

1. Extrair o ficheiro ZIP.
2. Abrir `index.html` num navegador.

Opcionalmente, iniciar um servidor local na pasta do projeto:

```bash
python3 -m http.server 8080
```

Depois abrir `http://localhost:8080`.

## Nota científica
As classificações familiares podem variar entre autores e disciplinas. O mapa distingue tipos definidos pela composição familiar de conceitos relativos à organização conjugal, residência e parentesco. A poligamia, a poliginia e a poliandria são apresentadas como categorias de estudo antropológico; não são formas de casamento civil reconhecidas em Portugal.
